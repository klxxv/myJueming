### 1.5 三级菜单模型

设置系统采用三级信息层级，而不是让左侧列表承载每一个细节：

| 层级 | 界面位置 | 文档层级 | 内容职责 | 示例 |
| --- | --- | --- | --- | --- |
| 一级 | 左侧设置分类栏 | H2 | 稳定的设置领域 | `辅助功能` |
| 二级 | 右侧分类首页中的分组卡片 | H3 | 同一领域内的功能组 | `动态与感知` |
| 三级 | 从设置行进入的详情页 | H4 或详情规格 | 集中的复杂选项、解释和预览 | `动态效果` |

三级详情页保留上一级返回路径，并在标题下显示完整位置，例如“辅助功能 > 动态与感知 > 动态效果”。左侧 H2 选中态保持不变，避免用户误以为进入了另一个主分类。

## 2. 设置系统的通用规则

### 2.1 设置作用域

| 作用域 | 保存位置 | 示例 | 不允许混入的内容 |
| --- | --- | --- | --- |
| 设备偏好 | 本机设置存储 | 主题、字号、触控板、桌宠角色 | 语料正文、Alignment、批注正文 |
| 账号偏好 | 账号服务 | 社区资料、通知偏好、跨设备设置同步 | 未经用户选择的本地语料 |
| 工程偏好 | `.jm` 工程内明确的 project metadata | 工程语言、导入来源、工程级发布记录 | 设备主题、窗口尺寸、账号凭据 |
| Provider / Plugin 偏好 | 本机安全配置与 Registry | Slot 绑定、执行位置、权限策略 | 插件直接修改 canonical data 的权限 |
| 会话状态 | 内存或临时 UI 状态 | 当前设置页、当前滚动位置 | Revision 或正式工程历史 |

### 2.2 即时生效与确认

- 主题、字号、界面缩放、触控板、动态效果、桌宠行为和通知偏好即时生效，不提供整页“保存”按钮。
- 登录、退出登录、撤销设备会话、上传、发布、删除下载内容、清理缓存、重置设置和切换远程 AI 必须有明确确认或结果反馈。
- 发布语料必须逐次确认语料范围、可见性和授权协议。全局默认值只能减少重复选择，不能跳过发布确认。
- 任何远程 AI、Agent 或插件第一次读取完整语料、访问网络或提出写入 Patch 时，都要显示权限范围。
- Revision 是正式历史，不提供“自动删除历史”或模糊的“释放全部空间”按钮。

### 2.3 状态与可见性

- 未实现的分类不显示。
- 已实现但因离线暂不可访问的在线分类可以显示离线状态和重试入口。
- Slot 使用 `BOUND`、`UNBOUND`、`DISABLED_BY_POLICY`、`INCOMPATIBLE_SCHEMA` 等真实状态，不能只用按钮颜色表达。
- 没有 Provider 时可以显示中性的能力说明和安装入口，但不能允许提交不可执行操作。
- 账号不是使用本地对齐器的前置条件。未登录用户仍可完整使用所有本地 MVP 功能。

### 2.4 iPadOS 式交互约定

- 左侧分类行为类似 iPadOS 设置：紧凑列表、清晰选中态、分组标题弱化。
- 右侧页面以 H2 标题开始，H3 功能组使用圆角卡片；组内设置行由分隔线连接。
- 行尾开关用于直接布尔偏好；行尾当前值加箭头用于进入三级详情页。
- 滑杆显示实时数值和边界含义，并支持键盘调整。
- 只读状态不伪装成按钮；危险操作不和普通开关混在同一行。
- 所有控件提供默认、悬停、焦点、按下、禁用、忙碌、成功和错误状态。

### 2.5 动效设置的分布与单一来源

动效选项可以出现在不同语境中，但不能各自保存互相冲突的总开关。所有模块读取同一个设备级 `MotionPolicy`；三级页面只是从不同入口编辑这份策略的不同字段。

| 入口路径 | 负责的动效内容 | 不负责的内容 |
| --- | --- | --- |
| `辅助功能 > 动态与感知 > 动态效果` | 全局动效模式、跟随系统“减少动态效果”、关闭非必要动画 | 不逐项管理桌宠角色行为 |
| `外观与阅读 > 界面动效 > 界面动画` | 页面转场、平滑跳转、高亮淡出、面板展开等界面反馈 | 不管理节能和桌宠动作 |
| `桌宠 > 行为与角色 > 桌宠动效` | 决明草摇摆、蝴蝶、追逐、探头和闲置动作 | 不能绕过全局减少动态效果 |
| `通用 > 性能与节能 > 动效性能策略` | 后台暂停、节能暂停、卡顿时自动降级、动画质量 | 不改变用户选择的角色或主题 |

动效策略按以下优先级合并：

1. 操作系统“减少动态效果”只能降低动画强度，不能被应用强制覆盖为更强。
2. 用户选择的全局动效模式决定允许的最高强度。
3. 节能模式、窗口失焦或性能自动降级可以临时进一步减少动画。
4. 界面动画和桌宠动画的局部开关只能在前三层允许的范围内生效。

关闭动画不等于移除状态反馈。加载、保存、错误、拖拽目标和跳转位置必须改用静态文字、图标、边框或即时高亮表达。

## 19. 设置搜索

设置搜索不是独立 H2 页面，而是左侧顶部的全局入口。

### 19.1 搜索范围

- 搜索 H2 分类标题、H3 功能组、设置项名称、同义词和平台名。
- 结果显示完整路径，例如“辅助功能 > 动态与感知 > 动态效果”。
- 不搜索账号令牌、工程正文、译文、批注或上传内容。
- 尚未上线或当前隐藏的分类不进入普通搜索结果。

### 19.2 搜索交互

- 选择结果后打开对应 H2 页面，并短时高亮目标设置行。
- 高亮尊重“减少动态效果”，不能使用闪烁。
- 无结果时提供清除搜索，不推荐不存在的设置。
- 键盘焦点从搜索结果进入设置行后保持可预测的返回路径。

## 22. 本文档冻结的设计决定

- 设置页采用 iPadOS 式左侧列表和右侧分组详情，不采用单页长表单。
- 账号是在线生态入口，不是本地对齐器的使用门槛。
- 本地工程不会因登录、启动、打开或进入社区页面而自动上传。
- 桌宠是窗口内可选功能，默认关闭，永远不覆盖语料正文和编辑控件。
- 辅助功能的产品底线始终生效，不能被用户关闭；设置页只提供个性化增强。
- 动效设置采用三级菜单分布：全局模式归辅助功能，界面动画归外观与阅读，桌宠动作归桌宠，后台和节能降级归通用。
- 所有动效入口共同编辑一份设备级 `MotionPolicy`；系统减少动态效果、全局模式、临时性能降级和局部开关按固定优先级合并。
- 关闭动效不能移除保存、错误、拖拽目标、跳转位置等必要状态反馈，必须提供静态替代。
- 发布语料必须逐次确认范围、可见性和授权协议。
- Agent 和插件不能直接修改 canonical store，只能通过 Kernel Command、Artifact 或 Patch Proposal。
- Revision 不属于可清理缓存，不提供自动删除历史设置。
- 当前未接通能力保持隐藏；完整蓝图不等于当前导航。
