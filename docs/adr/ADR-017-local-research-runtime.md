# ADR-017：本地 Slot、数据流与研究插件运行时

状态：Accepted，2026-09-13；依据用户对本地实施计划的明确执行授权。

## 决策

扩展 ADR-010／016 的初始 MVP 范围：实现本地 Slot／Schema／Operator 目录、显式多输入计划、快照数据池和可信进程外算法插件。既有 v1 分词方法和产物保持原格式及读取路径；新运行使用独立 v2 合同，不将 MethodRevision 当 canonical Revision。

29 个主 Profile Slot 与四个研究 Slot 有真实描述和 Schema 引用；状态以可执行实现及其资源为准，无实际 Provider 的能力保持 UNBOUND。设备功能意图、资源完整性、绑定兼容性和 Worker 驻留分别管理。开启功能授权宿主准备固定官方依赖；已完整随包时离线直接加载。插件不写 canonical 存储，不直接向 Agent／MCP 注入工具。

设备功能控制和资源注册表独立于普通设置 JSON，并由 Host 校验和持久化。公共方法目录定义作用域与原生权限；UI、内置 Agent、MCP 经同一 Host。长任务快速返回稳定 Run 身份，结果读取有界，取消按所有权校验。

人工译法判断使用结构化 ProjectSnapshot sidecar，携带来源 Revision、正文摘要、稳定 Segment 范围、分组及策略；经 Kernel 命令提交完整新 Revision。首次保存该扩展时工程合同为 1.1，新程序读取 1.0／1.1；旧程序必须拒绝 1.1，避免静默丢失研究事实。IPC 命令合同继续 1.0。历史恢复包含 sidecar；旧文本锚点失效时保留证据并待复核。

云端、headless、商业授权、账号和任意不可信插件执行不进入本次实现。此决策规定边界，不宣称所有实施阶段已完成；实际状态见实施计划及验证记录。

## 首版实施约定

- 旧 Slot 名称的等价别名与需要显式选择 Provider 的名称分开登记；不能把 `alignment.embedding` 静默映射成某个不存在的算法。
- 数据面采用 UTF-8 JSON 有界批次（8 MiB），Host 提供快照拉取 API，独立进程使用输入/输出帧；Arrow 与反向 Worker Data RPC 不作为首版已实现能力。
- 计算节点只输出派生产物或 KernelCommandProposal；文件保存和 canonical 提交由宿主完成。该版本不开放带写效果的插件节点。
- 兼容以准确 Schema 名称/版本及端口检查为准；v1 和 v2 保持独立路径，不自动重解释旧偏移。
- 缓存按 Revision 保守隔离，运行中数据 pin 优先于回收；每次 Run 保留实际 Provider 与资源指纹。
- 人工记录包含整个 n:m 上下文的指纹。恢复旧正文不降级 1.1 格式，防止历史中已存在的研究 sidecar 被旧程序漏读。
- 当前 XLM-R 只作为人工审核候选基线；平台与质量发布门槛见验证记录，不把模型烟测通过当作定位准确率合格。
