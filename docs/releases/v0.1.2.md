决明对齐器 v0.1.2，基于 GitHub main 的最新集成代码。

- 增加本地 Agent、MCP 接入与数据流工作区。
- 改进跟随系统的明暗/护眼主题、同步阅读进度、滚动标记与搜索结果显示。
- 提供 Windows x64 EXE/MSI 安装包、便携 EXE/ZIP，以及 macOS Universal DMG/ZIP；MCP 服务单独下载。

### 本次发布范围

本版本暂不随包提供 PyTorch、XLM-R 模型及其可选研究运行时。依赖该运行时的模糊匹配和自动词对齐功能不可用；启用时应用会提示研究资源未包含。基础双语阅读、人工对齐/审校、历史记录与 MCP 不依赖这些资源。

Windows 建议下载 `windows-x64-setup.exe`，macOS 下载 `macos-universal.dmg`。便携 ZIP 解压后运行；MCP 附件供需要外部 Agent 接入的用户使用。
